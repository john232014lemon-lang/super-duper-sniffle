# Bushel

Bushel is a family-friendly Flutter app for finding food banks and volunteering together. The first version uses local mock data so the core experience can be built and tested one small feature at a time.

Planned later integrations include Firebase for authentication and live data, plus an optional AI-assisted onboarding experience. Those services are intentionally outside the initial mock-first build.

## Run locally

```sh
flutter pub get
flutter run
```
